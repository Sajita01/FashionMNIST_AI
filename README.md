# FashionMNIST AI Classifier

## What it does
A deep learning model trained on the Fashion MNIST dataset 
that classifies clothing items into 10 different categories 
such as T-shirts, trousers, shoes, bags, and more.

## Tech Stack
- Python
- Jupyter Notebook
- TensorFlow / Keras
- NumPy / Matplotlib
- Fashion MNIST Dataset

## Fashion MNIST Categories
| Label | Class |
|-------|-------|
| 0 | T-shirt/top |
| 1 | Trouser |
| 2 | Pullover |
| 3 | Dress |
| 4 | Coat |
| 5 | Sandal |
| 6 | Shirt |
| 7 | Sneaker |
| 8 | Bag |
| 9 | Ankle boot |

## How it Works
1. Fashion MNIST dataset is loaded and normalized
2. Deep learning model built using Keras Sequential API
3. Model trained on 60,000 training images
4. Evaluated on 10,000 test images
5. Predicts clothing category from input image

## Results
- Successfully classifies all 10 clothing categories
- Visualized predictions with confidence scores
